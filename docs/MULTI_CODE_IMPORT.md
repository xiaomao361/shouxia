# 多码导入

## 解析与批次

同一条通知可以包含多个取件码，例如：

```text
【中通】包裹已到北门妈妈驿站，取货码9-4-0178、5-1-2889。
```

解析器生成两条记录，共享该通知中的地点、平台和导入批次。支持顿号、中英文逗号及重复标签；同一通知的重复码合并，列表中的电话、长运单号或门牌号按用途排除。

多码列表与多条通知分别处理。多条通知需要先确定边界，再关联各自的地点与快递信息，不能将第一条通知的地点分配给全部码。候选关系与核对规则见[识别机制](RECOGNITION.md)。

## 去重与兼容

首码保留整条通知的指纹，其余码使用派生指纹。旧版本仅保存首码时，重新导入可补充缺失码，并保留已有记录的标识与完成状态。

待取去重结合取件码、地点及快递上下文；相同短码不等于同一个包裹。完成后的短码可供新包裹复用。自动剪贴板导入遵守永久删除指纹抑制，主动粘贴仍可重新添加。

整批解析与去重后执行一次原子写入。写入失败返回错误，不报告成功；新增、重复及未处理数量分别呈现。此机制不自动迁移或重写历史记录。

## 测试

`PickupParserTests.swift` 与 `PickupRepositoryTests.swift` 覆盖分隔符、重复标签、无关数字、OCR 行、多通知关系、旧首码兼容、磁盘重读、删除抑制和写入错误。运行方式见[开发指南](DEVELOPMENT.md)。
