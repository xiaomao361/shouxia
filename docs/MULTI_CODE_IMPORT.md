# 一条通知中的多个取件码

2026-09-14：修复中通短信共用一个“取货码”标签时，只保存第一个码的问题。

- `取货码9-4-0178、5-1-2889` 导入为两个独立记录；支持顿号、中英文逗号及重复标签，同一条通知内相同码只保留一次。
- 一条通知中的码共用解析出的地点、平台和导入批次。补充“包裹在……妈妈驿站”的地点匹配。
- 手动粘贴、自动剪贴板、短信快捷指令使用批量解析；图片提取复用同一标签列表规则，保留 OCR 短横线空格处理。该功能按单条通知处理，不用于给不同地点的多条短信逐条配对。
- 无标签文本沿用原来的单码回退；自动剪贴板仍要求取件码标签。列表中的手机号、长运单号及三位门牌号不作为新增码。
- 文本整批解析、去重后只原子写入一次；写入失败抛出错误，界面不显示成功。提示区分新增与重复数量。

## 旧数据兼容

首码保留原整条短信的指纹，其余码使用各自的派生指纹，不修改存储结构，也不自动重写历史记录。旧版本已经保存首码时，重新导入原文仅补入缺失码，保留原记录 ID 和完成状态。自动剪贴板按各码指纹遵守永久删除抑制，手动导入仍可明确恢复。
