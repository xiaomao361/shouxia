# 识别回归数据

本目录保留版本化样本、预期约束和历史回放产物。当前机制见[本地识别](../RECOGNITION.md)，执行入口见[开发指南](../DEVELOPMENT.md)。

| 目录 | 内容 |
| --- | --- |
| `1.2.7/` | 识别核心的历史回放与验证，`review-fixes/` 包含复核输入及对照结果 |
| `1.2.8/` | 热修输入 `cases.jsonl`、修复前后回放及历史验证 |
| [1.2.9/](1.2.9/README.md) | 稳定性约束 `contracts.jsonl` 及历史验收摘要 |
| [研究数据](../research/2026-10-15-pickup-parsing/README.md) | 来源、标注、样本真值与研究基线 |

`check_pickup_recognition.py` 引用研究样本、1.2.7 复核样本、1.2.8 热修输入和 1.2.9 约束，并生成格式变体。数据路径由脚本使用，不随文档目录调整而迁移。

历史 `validation.json` 与回放文件记录当时的执行结果，不是当前源码的测试报告。构造变体属于同一模板家族，不能按文件行数扩大真实样本覆盖。新增样本须注明来源与预期依据；第三方样本保留其许可说明。
