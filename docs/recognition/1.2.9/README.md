# 稳定性回归约束

`contracts.jsonl` 保存候选关系与失败状态的构造输入，包括数字用途、同行字段、引号码、遮挡、更正及部分通知未处理。当前实现说明见[本地识别机制](../../RECOGNITION.md)。

## 代表约束

| 输入 | 预期 |
| --- | --- |
| 到件通知含尾号、日期或客服电话分机 | 识别其用途，不作为无标签码自动保存 |
| 收件人/地址与明确码同行 | 保留有效码，不排除整行 |
| `取件码1234，更正为56****` | 旧码被替代，新码不可用，不保存旧码 |
| 修改营业时间、日期或地址 | 不使原取件码失效 |
| `取件码1234、56****、9012` | 保留两个完整码并提示未处理项 |

## 执行

```sh
bash scripts/check_recognition.sh /tmp/shouxia-recognition-check
bash scripts/replay_pickup_samples.sh docs/recognition/1.2.9/contracts.jsonl
```

完整检查同时使用历史标注与构造格式变体，分别断言码、地点、平台、核对和遗漏状态。变更预期需提供语义理由，不从当前输出自动生成答案。

[validation.json](validation.json) 是 2026-10-19 对 1.2.9（25）源码执行的历史记录，包含源码哈希与结果摘要。它不表示当前工作树已执行检查，也不代表独立测试集、未知模板准确率或真实图片 OCR 验收。
