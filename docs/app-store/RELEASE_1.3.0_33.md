# 1.3.0 测试说明

本文件为 1.3.0（33）的本地测试说明，供分发时使用，不表示已同步 App Store Connect 或已公开发布。构建的处理与可安装状态应在分发渠道单独确认。

## 主要变化

- iOS 27 短信自动收码设置提供离线视频，分别演示模板触发配置与手动创建。
- 视频支持暂停、定位和重播，切到后台时暂停，同一设置会话保留位置。
- 完善本地识别、候选核对及遗漏提示，调整实时活动明暗外观同步。

## 测试重点

1. 从“设置 → 导入设置 → 设置短信自动收码”进入教程；检查短演示和完整创建演示能离线播放。
2. 检查暂停、定位、重播，以及切换到快捷指令后返回继续播放。
3. 按应用内说明完成系统配置，再用真实取件短信验证码和地点进入待取列表。
4. 检查覆盖更新后的已有记录、文字/图片/分享导入、取件完成与撤销。
5. 开启实时活动后检查锁屏和灵动岛可读性；应用关闭期间切换主题后，需再次打开收下同步外观。
6. 在 iOS 16、17、18、26 检查对应文字引导和既有导入行为。

观看视频或手动运行快捷指令不等于短信自动化配置成功。回归脚本只验证既定逻辑与标注输入，真实 OCR、系统触发和设备布局需另行验证。

反馈应包含应用版本、iOS 版本、入口、复现步骤、预期与实际结果。发送短信或截图前请移除私人信息。
