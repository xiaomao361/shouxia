## TestFlight测试说明（本地草稿）

本版新增iOS27短信自动收码离线教学。请从“设置 → 导入设置 → 设置短信自动收码”进入，正常模板路径观看“看操作演示”；无法打开模板链接时，展开“链接打不开？手动创建”查看完整演示。检查播放、暂停、拖动、重播，以及切到快捷指令再返回后继续观看。

重点请不熟悉快捷指令的测试者仅靠应用内引导完成配置，并用真实取件短信验证取件码与地点成功进入待取列表。看完视频或手动运行一次快捷指令不能代替此项验证。
