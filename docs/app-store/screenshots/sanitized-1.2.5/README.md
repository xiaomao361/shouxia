## 使用限制

7 张竖图为 852 × 1846；组件局部为 1774 × 887，灵动岛局部为 1672 × 941。保留原比例，不直接作为符合商店上传尺寸的成品。

AI 编辑可能改变字体、纹理或细节。公开使用前检查功能与文字准确性，并复核脱敏；OCR 检查不能保证没有遗漏。需要原始设备证据或正式商店截屏时，应另行采集并验证。
