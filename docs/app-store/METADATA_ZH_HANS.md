## 描述

收下是一款极简的个人取件码助手。

取件通知可能来自短信、快递柜、驿站或购物 App。收下把这些零散信息整理成清晰的待取卡片，让你打开 App 就能快速找到取件码和地点。

你可以：

• 复制取件通知后，一键粘贴并解析
• 从相册选择物流截图，在本机识别取件码
• 识别常见取件码、地点和来源
• 通过 iPhone“快捷指令”的信息自动化导入取件短信
• 自动避免同一条通知被重复添加
• 轻点卡片，用大字展示取件码；同一地点多件可以左右切换
• 向右滑动，轻轻完成取件
• 查看、归档、恢复或永久删除历史记录

隐私是默认设置：

• 取件通知和解析结果只在本机处理、保存
• 不需要注册账号
• 不包含广告或第三方分析 SDK
• 不读取短信历史
• 不读取其他 App 的通知
• 不上传或保存你选择的物流图片
• 只有在你点击粘贴按钮后才读取剪贴板

短信自动导入需要你在系统“快捷指令”中完成一次个人自动化设置。支付宝及其他第三方 App 的通知仍需主动复制后粘贴。

收下不做物流追踪，也不制造待办压力。它只想让取件这件小事，更轻松一点。
