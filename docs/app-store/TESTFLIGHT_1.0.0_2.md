# 收下 1.0.0 (2) TestFlight 测试说明

Status: Installed — `1.0.0 (2)` 已于 2026-07-30 09:22（Asia/Shanghai）上传成功，随后完成 App Store Connect 处理；用户已确认在真机安装 TestFlight 构建。产品验收进行中。

## Beta App Description

收下是给实际去取快递的人使用的取件码收件箱。自己的取件短信可以通过系统自动化进入，家人朋友托取的文字或截图可以通过主动粘贴和本机识图进入。所有取件信息和解析结果只保存在本机。

## What to Test

本轮重点验证新的双入口产品模型和正确的短信自动化设置：

1. 从未安装“收下自动收码”普通快捷指令的状态开始；
2. 仅按 App 内说明建立普通快捷指令；
3. 建立“信息”个人自动化，选择“立即运行”并运行“收下自动收码”；
4. 用一条真实测试短信确认完整正文自动进入；
5. 确认 App 不在前台时仍能保存；
6. 重复传入同一正文，确认不会重复添加；
7. 复制家人朋友发来的取件文字，点击“粘贴取件信息”；
8. 选择一张对方发来的物流截图，验证本机识图和候选确认；
9. 到取件现场模式查看大字取件码，并完成、撤销和归档记录；
10. 在不询问开发者的情况下，记录任何看不懂、找不到或无法继续的步骤。

## 反馈请包含

- iPhone 型号与 iOS 版本；
- 配置自动化花费的时间；
- 卡住的页面和原文；
- 自动化是否显示运行；
- 取件短信是否真的出现在收下；
- 取件信息来自自己的短信、聊天文字还是聊天截图；
- 是否需要标记“为谁取”；
- 从聊天保存图片再导入是否过于繁琐；
- 不含真实手机号、地址或取件码的脱敏截图。

## 已知边界

- 收下不能替用户创建或查询个人自动化；
- App 内可通过 iCloud 分享链接添加“收下自动收码”；若链接不可用，仍可按手动说明建立普通快捷指令；
- 只支持进入苹果“信息”App 的 SMS/iMessage 自动化；
- 不读取支付宝或其他第三方 App 的通知；
- 当前显示录入时间，不保证获得短信原始接收时间；
- 本 Build 用于 TestFlight 验证，不代表正式 App Store 发布候选已经通过验收。
