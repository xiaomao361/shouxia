# 收下 1.2.12（28）实时活动系统材质

2026-10-20。用户认可保留实时活动、优先融入系统材质的优化建议，授权实施；另询问1.3.x时机。本版沿用1.2.x体验修正范围，不新增业务功能或预设1.3正式发布日期。

## 调整与验收口径

- 锁屏无自绘背景，`activityBackgroundTint(nil)`请求系统默认背景材质，`activitySystemActionForegroundColor(nil)`采用默认清除按钮色，取件信息使用语义主次文字色。
- 移除1.2.11主App外观采集、持久化和活动负载appearance字段；旧偏好键留存但不再读写，旧活动负载里的退役字段由解码器忽略，取件内容保持。既有记录存储及识别规则不变。
- 灵动岛/Mac保留系统展开容器和白字，橙色自定义keyline保持移除；取件码、地点、件数层级保持。
- 当前验收以融入系统、文字可读和滑动无异常色边为准，允许系统按壁纸、显示位置、息屏环境决定深浅，不强制全局浅色时必须白底。1.2.10默认材质仍为深色的用户反馈是事实，不因本版改变目标而改写成当时已验收。
- 公开API请求系统默认材质不能证明设备实际有与普通通知一致的透明/玻璃效果；须用户检查真实表现，若仍不符合预期再定位平台材质行为，不能将“没有奶白底”宣称为“玻璃已验收”。
