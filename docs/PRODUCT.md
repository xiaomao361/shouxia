# 功能与数据约定

## 产品范围

收下面向实际领取包裹的人，管理取件通知的录入、查看、完成和代取交接。应用采用设备本地解析与存储，不提供物流追踪、账号、家庭同步或云端回执。

## 导入

| 入口 | 行为 |
| --- | --- |
| 主动粘贴 | 解析完整通知，也接受独立的 4 至 8 位数字取件码 |
| 前台剪贴板识别 | 默认关闭；开启后仅在前台且剪贴板变化时尝试一次，采用更严格的识别条件 |
| 短信 App Intent | 接收系统快捷指令传入的文本，不读取短信历史 |
| 相册 | 最多选择 5 张图，在本机 OCR；简单明确结果可直接添加，其余进入核对 |
| 系统分享扩展 | 接收文字或最多 5 张图，核对后保存至本地队列，主应用回到前台后入库 |
| 收下交接包 | 校验文件并预览，确认后批量导入 |

地点缺失时，可使用用户配置的常用取件点补全未来导入，并保留来源提示。冲突地点需要确认，不用常用地点覆盖冲突。已有记录不会因修改常用地点而自动重写。

## 记录与完成

记录包含取件码、地点、来源、必要通知内容、指纹、导入时间，以及可选的导入批次、地点来源和完成时间。文字导入保留通知原文；图片与系统分享只保存最小取件字段和必要片段，不保存原图或 OCR 全文。

待取卡片可打开大字模式。同地点或同批次记录可连续查看；完成一件后进入下一件。首页支持滑动完成与短时撤销。历史默认筛选最近 30 天，可查看全部、恢复待取或确认永久删除；筛选不会删除旧记录，旧归档仍可查看。

永久删除后，本机会保留用于阻止自动剪贴板重复导入的单向指纹；主动粘贴可重新添加。应用没有废纸篓或云端恢复功能。

## 重复导入

去重结合原文或来源指纹，以及当前待取记录的取件码、地点和快递信息。同码不同地点不直接合并，缺少上下文时保留核对。多码通知为各码生成可区分的指纹；已完成包裹的短码可以被后续新包裹复用。详见[多码导入](MULTI_CODE_IMPORT.md)。

## 代取分享

- **普通文字**：仅预览与复制，接收方无需安装收下，发送方记录仍为待取。
- **收下交接包**：系统分享成功且无错误后，发送方记录标记为“交给别人”；取消或失败不改变状态。接收方需要安装收下，预览确认后导入。

交接包是本地快照。分享成功表示发送侧完成交接操作，不表示对方已导入或取到包裹，双方状态不会同步。详见[分享约定](PLAIN_TEXT_SHARING.md)。

## 系统能力

小组件读取 App Group 中的最小快照；实时活动由用户主动开启，并受系统权限、更新调度和会话时长限制。应用无法代替用户创建或查询短信自动化，也不主动读取其他应用的通知。详见[系统展示](SYSTEM_SURFACES.md)与[使用帮助](app-store/SUPPORT_ZH_HANS.md)。
