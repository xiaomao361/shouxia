# 普通文字与交接分享

首页“请人帮取”提供两种方式：默认的“收下交接包”和“普通文字”。两者都可选择多件待取记录，每次最多 100 件。

## 普通文字

选择记录后预览文字，点击“复制文字”，再粘贴到聊天。接收方无需安装收下。输出示例：

```text
帮忙取这 3 件快递：

北门驿站
取件码：3-2-4012（淘宝）
取件码：1-3-5066（拼多多）

丰巢
取件码：829146
```

文字只包含所选记录的取件码、地点和平台，不附短信原文、图片、指纹、记录标识或推广链接。用户填入的地点也会导出，发送前应检查预览。

分组采用地点规范化规则，保留地点首次出现顺序及组内记录顺序。同码不同地点的记录不会仅因码相同而省略。缺失地点显示“地点待确认”，常用地点附“常用取件点，请确认”。

预览与复制不改变待取状态；确认取到后由用户手动完成。空选择不提供复制操作。

## 收下交接包

`.shouxia` 文件包含取件码、地点、平台及用于重复导入保护的来源记录标识，不包含短信原文、图片或独立的手机号、运单号字段。

发送方通过系统分享面板发送文件。仅当分享回调表示完成且没有错误时，所选记录才离开待取，标记为“交给别人”。取消或报错不改变记录。

接收方打开文件后，应用校验版本、数量、字段长度及取件码格式，展示预览；确认后批量写入本地记录。同一来源记录通过交接指纹防止重复导入。

交接包是发送时的快照，不提供账号、云同步或回执。系统分享完成不表示对方已收到、导入或取到包裹。

## 回归范围

`ShouxiaTests/PickupShareTextTests.swift` 覆盖地点分组、缺失地点提示、同码保留、字段裁剪、空选择与数量限制，以及专用包的成功、取消和错误回调。实际聊天粘贴和跨应用文件交接需单独验证。
