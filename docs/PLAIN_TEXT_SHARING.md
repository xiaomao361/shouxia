## 使用方式

首页“请人帮取”默认选中第一个选项“收下交接包”；第二个选项是“普通文字”。选择普通文字后，选择这次要请人帮取的记录，查看文字预览后，点击“复制文字”并自行粘贴到聊天。接收方无需安装收下。

示例：

```text
帮忙取这 3 件快递：

北门驿站
取件码：3-2-4012（淘宝）
取件码：1-3-5066（拼多多）

丰巢
取件码：829146
```

## 内容与状态约定

- 仅导出所选记录的取件码、地点和平台；不附短信原文、记录 ID、指纹、图片或推广链接。不额外导出手机号、运单号和商品字段；用户自行填入地点的内容会作为地点分享，发送前可在预览中检查。
- 按现有地点规范化规则分组，保留地点首次出现顺序和组内记录顺序；不做地理推断，也不因取件码相同而丢弃所选记录。
- 地点缺失或全空白时显示“地点待确认”。常用取件点保留“常用取件点，请确认”提示，不冒充识别出的地点。
- 延续现有选择上限，每次最多 100 件；取消全部选择时不提供分享或复制操作。
- 预览和复制不完成交接，不更改待取记录。复制按钮只报告文字已复制，不报告对方已经收到或取到。
- 确认对方取到后，用户手动收下。此次不增加云端回执或同步状态。
- 默认的“收下交接包”仍发送原 `.shouxia` 文件：系统分享成功且无错误后，才调用原交接流程；取消或报错不触发交接。接收方仍需安装收下。
