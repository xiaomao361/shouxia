## 文档维护

公开文档描述功能、接口、设计约束、复现方法与用户可见变更。版本变更集中维护，避免在多份指南中重复分发状态。构建日志、签名凭据、安装回执和临时排查结果保存在本地忽略目录，不作为功能文档。

研究材料保留采集日期、源码基线、失败结果、来源和许可；历史实验结论应注明适用基线，不直接代表当前实现。更新功能说明时同步检查支持页和相关文档链接。
