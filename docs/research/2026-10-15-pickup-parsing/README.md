# 取件通知样本与本地解析研究

研究日期：2026-10-15。基于收下 `96dcd6190342c060678ec94eb729bdc62f2c832d` 及当时工作树的解析相关文件；具体 SHA-256 在 `baseline-environment.json`。本轮仅研究，未修改应用代码、配置或测试，未提交、推送、安装或发布。

**结论：优先修通知分段、数字角色和字段关联，再补句式；继续采用 Apple Vision + 本地规则。** 增加一串站名关键词无法解决同屏跨通知串配、手机号尾号误提取、英文字母前缀截断等已复现问题。

44 条 = 7 条公开通知记录 + 2 条机构公开模板 + 3 条短信厂商模板 + 1 条厂商码格式 + 4 条开源用例 + 27 条人工边界用例。人工用例不冒充真实短信；公开通知记录含脱敏改写、掩码和二手转录，具体层级逐条注明。初步分为 37 个模板/机制家族，不代表覆盖了全国格式。

43 条有可执行文本，T05 仅结构摘要；回放共 169 次入口调用。三张公开图的 macOS Vision 探针为 1 次成功、2 次计算引擎报错。**这些结果不能换算成真实用户准确率，也不证明 iPhone 上的 OCR 或交互验收通过。** 全部样本已被本轮研究看过，没有宣称独立留出集。

下一步开发前最有价值的输入：用户真实的错地点、错码、错快递各类案例，以及多条通知同屏的原始版式。优先同时提供脱敏截图、可复制正文和正确对应关系；保留位数、连字符、尾号角色及断行位置。当前研究交付不以这些补充为前提。
