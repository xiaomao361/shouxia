# 短信自动收码离线教学

1.2.12（31）引入，1.2.12（32）优化播放器样式，2026-10-21统一进入[1.3.0（33）候选](app-store/RELEASE_1.3.0_33.md)。用户选择应用内离线教学，不使用 App Store 预览或第三方视频网站。视频、封面全部随安装包分发，教学播放不发起外部请求；现有 iCloud 模板添加入口保留。

## 两种用途

- 正常模板路径：「第二步 → 设置收到短信时运行」下提供「看操作演示」，约10秒，只讲编辑已添加的“收下自动收码”、添加“信息”触发器、信息包含“取件”。不要求重复搭建模板中的获取文本和保存操作。
- 手动路径：「链接打不开？手动创建」展开后提供「看完整创建演示」，约28秒，从触发条件到文本输入、保存到收下。原片未录到最后选择“短信内容”参数的动作，使用原画面圈选和字幕提示选择上一步“文本”，没有伪造完成状态。
- 视频只在系统主版本为27时显示。iOS16及17/18/26继续显示各自的文字引导；其他未来版本不自动套用27视频。

## 播放与资源

`AutomationTutorialView.swift` 提供本地封面卡片、按需加载的 AVPlayer 和全屏原生控件。32改为收下自适应背景、圆形关闭/重播按钮，视频在可用空间内按9:16比例居中适配，用28pt连续圆角、细边线和轻阴影呈现；清除原生播放器外层默认背景并裁切圆角，避免黑色留边。底部提示与错误页同步使用应用主题。用户点击后开始播放，可暂停、拖动和重播；切到后台或关闭播放器时暂停，返回后由用户继续播放。同一设置页会话的两段视频分别保留播放器和位置；不承诺关闭设置页或重启应用后续播。关闭画中画和外部播放，不修改系统音频会话。

缺失文件显示“教学视频未能加载”，解码或播放失败显示“视频暂时无法播放”，均可返回文字步骤或重试。失败不会隐藏首页入口，也不会标记自动化已完成；旧加载的迟到错误不能覆盖当前加载状态。
