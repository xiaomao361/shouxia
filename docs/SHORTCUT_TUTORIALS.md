# 短信自动收码离线教程

## 内容与入口

iOS 27 的短信设置页内置两段操作演示。视频与封面随安装包分发，播放无需访问第三方视频服务；添加快捷指令模板仍通过 Apple iCloud 链接完成。

| 入口 | 内容 | 时长 |
| --- | --- | --- |
| “第二步 → 设置收到短信时运行 → 看操作演示” | 在已添加的快捷指令中设置“信息”触发器和“信息包含取件”条件 | 约 10 秒 |
| “链接打不开？手动创建 → 看完整创建演示” | 手动创建流程及文本参数连接 | 约 28 秒 |

完整演示使用画面标注提示将“短信内容”连接到上一步“文本”。教程仅在系统主版本为 27 时显示；其他系统提供对应文字步骤。操作说明见[使用帮助](app-store/SUPPORT_ZH_HANS.md)。

## 播放行为

`AutomationTutorialView.swift` 使用本地封面和按需加载的 `AVPlayer`，通过全屏原生控件提供暂停、定位和重播。播放器采用应用主题背景，视频按 9:16 比例适配，并支持明暗外观。

进入后台或关闭播放器时暂停，返回后由用户继续。同一设置会话中的两段视频分别保留位置；关闭设置页或重启应用后不保证续播。画中画与外部播放关闭，播放器不修改系统音频会话。

缺失文件和解码失败分别提供错误提示，用户可重试或返回文字步骤。播放完成不标记自动化已配置，也不隐藏设置入口；是否成功须通过真实短信导入验证。
