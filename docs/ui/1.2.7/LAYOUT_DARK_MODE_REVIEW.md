# 1.2.7（21）排版与暗色模式检查

> 历史开发复核；当前上传和2026-10-16用户报告的送审状态见[1.2.7（23）发布记录](../../app-store/TESTFLIGHT_1.2.7_23.md)。

## 已修正

- 历史时间标签固定宽30点是断行的直接原因。改为自然宽度的标签列与数字日期列，放不下时切成上下布局。日期遵循系统地区和时间偏好，缩短展示而不改变存储时间。
- 历史和待取卡片共用地点标题布局：短地点与品牌同行，空间不足时品牌/托取状态另起一行，地点允许完整换行。
- 图片核对和托取选择将品牌放在内容列，不再挤压地点与代码；无障碍字体下，图片/分享核对的更正操作和首页导入操作改为上下排列。
- 待取代码、取件台长码使用完整换行回退，不以极小字号或省略号勉强塞进一行。取件台支持垂直滚动，编辑页可扩大到large。
- 完成提示取消固定高度；关闭、撤销操作至少44点。按钮文字可换行并随字体增高。
- 辅助文字、状态和警告使用专用深浅色文字token，保留原有柔和背景色。阴影不再复用暗色时变白的正文颜色。
- 锁屏实时活动的固定浅色背景、正文改为自适应配色；灵动岛保持其黑底所需的白色文字。

检查范围包含首页/待取卡片、历史、取件台/编辑、图片核对/候选编辑、分享扩展、托取选择/核对、设置/自动化/关于、小组件与实时活动的源码。未进行手机、模拟器或窗口的UI操作。
