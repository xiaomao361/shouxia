## 已处理的遗漏

| 位置 | 原状 | 修正与原因 |
| --- | --- | --- |
| 隐私、托取说明 | “地点和平台” | 统一“取件码、地点及快递信息”，与快递公司/取件服务角标相容，存储字段不变。 |
| 托取分享说明 | “发送成功后”“已发送” | 使用“完成系统分享后”“已分享”，不把系统分享回调说成对方已收到。 |
| 图片核对常用地点提示 | 不论候选是否缺地点都显示“将使用” | 仅已选候选缺少地点且无冲突时显示，避免完整地点也暗示会被覆盖。 |
| 候选更正、导入设置 | 常用地点的使用条件不清 | 明确地点可留空、已设置常用地点时才使用；有歧义仍须更正。 |
| 地点冲突提示 | “更正或确认”，但勾选已禁用 | 明确“请先点‘更正’核对”，与实际可用操作一致。 |
| 分享核对 | 品牌角标缺失；零选择显示保存0个 | 补角色明确的品牌角标及读屏提示；零选择显示“请先选择取件码”；分清保存与下次打开App加入待取。 |
| 分享失败页 | “返回”实际关闭扩展 | 改为“关闭”。 |
| 托取接收 | 导入失败的notice留在底层页 | 当前核对页显示失败信息，保留包裹和重试按钮，不关闭核对。 |
| 图片、托取核对 | 地点最多两行 | 允许完整换行，方便保存前核对长地点。 |
| 取件台页码 | 圆点数量没有上限 | 超过七件仅保留完整文字页码；页码文字可换行，避免大量圆点横向溢出。 |
| 主要按钮 | 禁用状态仍沿用正常填色视觉 | 显式降低禁用态不透明度，操作仍由既有disabled条件控制。 |
| 历史空状态 | 只提取完的包裹 | 说明已取到和已交给别人两种记录。 |

这些修改延续22默认选中的交互，不改解析、候选身份、数据库结构、队列内容或保存成功标准。
