# shouxia

“收下”是一款面向个人的极简 iOS 取件码助手：用户粘贴取件通知，或通过系统通知自动化传入文本；App 提取取件码与地点，取件后用一次滑动完成。

## 当前阶段

项目已经建立首个 SwiftUI 纵向薄切片，最低支持 iOS 17。原始通知会经过本地解析、内容指纹去重和本地 JSON 存储，再显示为待取卡片。收下后会进入带录入、收下时间的记录页，并可继续归档、恢复或永久删除。

## 产品边界

- 第一版只解决取件通知的收集、快速查看、完成和轻量记录管理。
- 默认本地处理和存储，不依赖账号、云端或物流平台 API。
- 不做物流追踪、家庭共享、聊天机器人、信息流或 Android 客户端。
- 核心验证是近乎无摩擦的录入，以及克制但令人满足的完成体验。
