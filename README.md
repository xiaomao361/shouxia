# shouxia

“收下”是一款给实际去取快递的人使用的 iOS 取件码收件箱：自己的取件短信可以通过个人自动化进入，他人托取的文字可以主动粘贴，也可在用户开启后于打开 App 时自动识别发生变化的剪贴板；聊天里连续收到的物流截图可以从相册一次选择最多五张并在本机合并识别。需要请别人代取时，可以把多件待取信息按地点整理成普通文字，预览并复制给未安装收下的人，待取状态不变；也可以发送本地“收下交接包”，系统分享成功结束后标为“交给别人”。App 提取取件码与地点，取件后用一次滑动完成。

App Icon 以“杏桃包裹 + 云白取件卡”为核心图形，直接表达 App 管理的是附着于包裹的取件信息；Logo 与 App 内空状态复用同一套几何语言。

## 当前阶段

当前源码为 1.2.8（24），最低部署版本为 iOS 16（旧系统实测待完成）。原始文本会经过本地解析、原文指纹与当前待取上下文双层去重和本地 JSON 存储，再显示为轻量云白纸签；相册图片由 Apple Vision 在本机 OCR，多图候选按取件码、地点和快递信息去重，只保存取件码、地点、来源和必要片段，不保存原图与无关全文。导入设置可配置只作用于未来记录的常用取件点，以及默认关闭的前台剪贴板自动识别。轻点卡片可进入取件现场大字模式，同地点或同批导入的多个包裹可以左右切换；向右滑动后，卡片会轻微下沉、缩小并淡出。收下记录默认显示最近 30 天，可查看全部、设为待取或确认后永久删除；旧归档记录仍可查看，不自动删除。首页明确区分“自己的取件短信”和“他人托取”两类入口；待取记录可批量生成 `.shouxia` 交接包，系统分享完成后发送方记录离开待取并标记为“交给别人”，接收方打开后预览确认导入。短信自动收码按系统版本引导：先从 iCloud 添加“收下自动收码”，iOS 27 在其中添加“信息”触发器，iOS 17、18、26 另建信息个人自动化并选择立即运行；iOS 16 使用个人自动化，收到短信后需确认运行；首页设置入口支持手动隐藏，首次短信来源导入后只自动隐藏一次，并可从“设置 → 导入设置”恢复。

## 产品边界

- 第一版只解决取件通知的收集、快速查看、完成和轻量记录管理。
- 默认本地处理和存储，不依赖账号、云端或物流平台 API。
- 数据分析和统计留到有真实使用数据后再定义，不进入 1.0。
- 不做物流追踪、家庭共享、聊天机器人、信息流或 Android 客户端。
- 核心验证是近乎无摩擦的录入，以及克制但令人满足的完成体验。

## 1.2.7 本地识别核心改进

取件文字、短信自动化和截图共用本地解析核心；内置快递公司与取件服务词库，购物平台不纳入新识别。优先处理通知边界、数字角色、地点边界和同码不同地点的身份保留；有码标签或明确凭码领取句式才从完整通知提取，主动粘贴/分享单独的码仍支持。自动短信与自动剪贴板不把裸数字当取件通知。部分通知无法提取明确码时保留可用结果并提示遗漏。

旧记录不自动重算；新记录品牌标签优先显示快递公司，未知时显示取件服务。相同码但地点/快递信息不同、或一方缺上下文时保留供核对，可能比旧版多出重复候选。实现、验证和边界见 [识别改进说明](docs/recognition/1.2.7/IMPLEMENTATION.md)。相关改进已包含在 1.2.7（23）上传归档中；上传和用户报告的送审记录见[发布记录](docs/app-store/TESTFLIGHT_1.2.7_23.md)。
